# Human silhouette source

`human-silhouette.svg` is the unmodified **Human body silhouette.svg** from Wikimedia Commons, downloaded 14 November 2026. The [source page](https://commons.wikimedia.org/wiki/File:Human_body_silhouette.svg) releases the work into the public domain worldwide, with unrestricted use where legally possible. The underlying image is attributed to Mikael Häggström and the SVG modification to RexxS.

Original URL: https://upload.wikimedia.org/wikipedia/commons/f/f4/Human_body_silhouette.svg

Original SHA-256: `d0e37b1a7b06c9db1e4c822c3b5189f3d9da4335cd2c543d04ec2e255ed49f9e`.

`body-systems.svg` retains that exact path and its translation as clipping geometry. AURA-Bio adds symbolic, keyboard-operable selectors for six systems, neutral unknown/overdue patterns, and a habitat frame. The regions are navigation aids, not anatomical localization or diagnoses; immune function is body-wide and metabolic has no measurement. All SVG geometry is served locally; there is no runtime web dependency.

Existing teammate PNG and organ assets are unchanged and are not used for the new body selector.
